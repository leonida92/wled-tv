# Architecture Deepening, Diagnostic Coordination, and Service Consolidation

Deepened the core domain, engine, network, and service modules while eliminating leaky UI workarounds and over-fragmented single-caller helpers (superseding Pass 5's `AmbientLockManager` and `DisplayPowerMonitor` extraction):

- **Optical Domain & Persistence (`PresetProfile`, `CaptureSettings`, `ConfigRepository`)**: Separated screen `CaptureSettings` and per-device hardware strip format (`colorOrder`, `isRgbw`, `rgbwMode`) from optical `ColorCalibration`. Folded `ConfigSchemaMigrator` and backup export/import I/O into `ConfigRepository` with typed `applyPreset`, `updateDeviceCalibration`, and `updateCaptureSettings` mutations and an isolated `encodeDeviceJson` / `decodeDeviceJson` codec for `EditDeviceActivity` draft state (`EXTRA_DEVICE_DRAFT_JSON`).
- **Diagnostic Streaming (`DiagnosticStreamCoordinator`, `AmbientStreamingEngine`)**: Extracted UI preview and HSV test loops into `DiagnosticStreamCoordinator` with reusable zero-allocation frame buffers and reference-counted `DiagnosticOverrideSession` (`acquireDiagnosticOverride()`), keeping `ScreenColorProcessor.encodeWireFrame` internal.
- **Fleet & Reachability Lifecycle (`WledControllerClient`, `WledFleetCoordinator`)**: Deleted dead `WledDiscovery` and global `DeviceReachabilityCache`, collapsed `DefaultWledControllerClient` lazy NSD initialization, added instance-scoped `reachabilityFlow` / `observeReachability` to `WledControllerClient`, and introduced `FleetCoordinator` / `WledFleetCoordinator` for atomic device toggle, removal, identification, and discovery.
- **Foreground Service Consolidation (`AmbientCaptureService`)**: Consolidated `AmbientLockManager` and `DisplayPowerMonitor` back into `AmbientCaptureService`, replaced mutable `isRunning` with `StateFlow<Boolean>`, removed duplicate overlay receiver registration in `SamplingOverlayManager`, and replaced name-based heuristics in `SamplingOverlayView` with `DeviceType` inside `DeviceOverlaySnapshot`.
